### The deck.cool family

Unstyled React packages built on the browser's own scroll snap, `<video>` and `<dialog>`. Little JavaScript, no styles. All at [deck.cool](https://deck.cool), source in [deck-cool](https://github.com/pedrosousa13/deck-cool).

- **[carouseldeck](https://carousel.deck.cool)**: a carousel that lets the browser do the scrolling. Native momentum, snapping and focus scrolling. `@carouseldeck/react`
- **[playdeck](https://play.deck.cool)**: a video player you compose, not one you configure. Native video, HLS, YouTube, Vimeo and Wistia. `@playdeck/react` · [repo](https://github.com/pedrosousa13/playdeck)
- **[pagedeck](https://page.deck.cool)**: a React framework for CMS-driven sites. Zero JavaScript until a page needs it. `npm create pagedeck` · [repo](https://github.com/pedrosousa13/pagedeck)
- **[drawerdeck](https://drawer.deck.cool)**: a drawer that lets the browser drag.

### Learn vim

- **[Vimaminute](https://vim.pedrosousa.me)**: learn vim motions on real React edits, right in the browser. Progress stays on your device, so coming back costs nothing.

### Browser extensions

- **[Ferry](https://github.com/pedrosousa13/ferry)**: URL redirector that never watches you. Native `declarativeNetRequest`, no telemetry.
- **[JSON Bonsai](https://github.com/pedrosousa13/JSON-Bonsai)**: JSON viewer that stays smooth on 100k-node payloads.
- **[Cue](https://github.com/pedrosousa13/cue)**: media controls for every tab, from the toolbar or the side panel.
- **[imgwhy](https://github.com/pedrosousa13/imgwhy)**: explains why the browser downloaded *that* image from a `srcset`.
